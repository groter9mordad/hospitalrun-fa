# راه‌اندازی کامپیوتر اصلی RunCDX

این پوشه برای نصب خودکار پایگاه دادهٔ مرکزی مطب روی ویندوز ۱۰ و ۱۱ است. برنامه روی
همهٔ کامپیوترها پایگاه دادهٔ محلی خودش را دارد؛ CouchDB فقط نسخه‌های محلی را در شبکهٔ
مطب با هم هماهنگ می‌کند. در نتیجه خاموشی مودم یا کامپیوتر اصلی، کار روزانه را متوقف
نمی‌کند.

## اجرای پیشنهادی از داخل RunCDX

مدیر در برنامه به «تنظیمات ← شبکهٔ داخلی مطب» می‌رود و دکمهٔ «آماده‌سازی خودکار
کامپیوتر اصلی» را می‌زند. برنامه همین اسکریپت را با تأیید UAC ویندوز اجرا می‌کند و
پس از پایان، تنظیمات اتصال را خودکار داخل RunCDX ذخیره می‌کند.

## اجرای دستی برای پشتیبانی فنی

۱. PowerShell را با گزینهٔ **Run as administrator** باز کنید.

۲. وارد پوشهٔ پروژه شوید و اجرا کنید:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\deployment\windows\Install-RunCDXServer.ps1
```

اسکریپت نسخهٔ پین‌شدهٔ Apache CouchDB را دریافت می‌کند، SHA-256 رسمی آن را بررسی
می‌کند، سرویس ویندوز و دیتابیس `hospitalrun` را می‌سازد، CORS و فایروال را فقط برای
شبکهٔ محلی تنظیم می‌کند و مشخصات اتصال را در مسیر زیر می‌گذارد:

```text
C:\ProgramData\RunCDX\clinic-connection.json
```

بعد از نصب، مدیر می‌تواند فایل اتصال سیستم‌های دیگر را از صفحهٔ شبکه در RunCDX
ذخیره کند. این فایل شامل رمز همگام‌سازی است و باید بعد از واردکردن در کامپیوترهای
مطب حذف یا فقط نزد مدیر نگهداری شود.

## نکتهٔ امنیتی

- رمز شبکه تصادفی ساخته می‌شود و کامپیوترهای دیگر فقط با همان حساب همگام‌سازی وصل
  می‌شوند.
- رمز مدیر CouchDB جداست و فایل آن فقط برای Administrators و SYSTEM ویندوز قابل
  خواندن است.
- پورت ۵۹۸۴ فقط برای `LocalSubnet` و پروفایل Private/Domain باز می‌شود؛ اینترنت برای
  کار برنامه یا همگام‌سازی لازم نیست.
